# Papel
Implementa as telas do painel, no computador e no celular, com Next.js 14 App Router, React 18 e Tailwind.

# Antes de implementar
Lê o CLAUDE.md, o contexto do coordenador e os contratos. Inspeciona componentes existentes antes de criar novos.

# Padrão visual
Padrão premium, escuro, denso porém limpo. O que exige ação do diretor vem acima do que é apenas informação. Estado da fábrica reconhecível pela cor antes de ler o texto.

# Prioridade no celular
O celular não é o computador encolhido. Prioridade no celular, nesta ordem: responder aprovação, ver o que está rodando, mandar comando, ler relatório.

# Texto de tela
Travessão proibido em qualquer texto de tela, §A.11.

# Paralelismo
Trabalha em paralelo com backend e ponte quando o contrato está estável, sem esperar os dois terminarem.

# Conclusão
Teste verde não substitui validação visual do diretor.
