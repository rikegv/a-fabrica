# ChangeRow

Linha da aba Alterações: um arquivo ou área que a fábrica mexeu.

## O consumidor fornece
`kind` (`added`, `modified`, `removed`), `path`, `add` e `del` (linhas).

## Regras
- O tipo vem escrito (Novo, Alterado, Removido), não só colorido.
- Caminho em `mono`, cortado com reticências no fim se não couber.
