# Tabs

Abas da tela Fábrica: Atividade, Tarefas, Relatórios, Alterações.

## O consumidor fornece
`tabs` (`id`, `label`, `count` opcional), `value`, `onChange`.

## Regras
- Controle segmentado de vidro: a aba ativa ganha `glass-strong` e o fio de luz. Nada de cor de estado aqui.
- No celular as quatro abas dividem a largura igualmente, sem rolagem horizontal, e os contadores somem.
