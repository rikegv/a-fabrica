# Segmented

Escolha única entre 2 a 4 opções curtas, em vidro: período, filtro, modelo.

## O consumidor fornece
`options[]` (texto, ou `id`, `label`, `hint`, `disabled`), `value`, `onChange`, `block` para ocupar a largura toda.

## Regras
- Até 4 opções. Mais que isso vira lista.
- `hint` só quando ajuda a decidir (ex.: "mais econômico" no modelo).
- Filtros de uma tela ficam numa linha só, no cabeçalho do painel.
