# Toggle

Liga e desliga uma preferência, com efeito imediato.

## O consumidor fornece
`label`, `hint` opcional, `checked`, `onChange(booleano)`, `disabled`.

## Regras
- Use para preferências que salvam na hora (avisos no celular). Para escolher entre opções, use `Segmented`.
- O rótulo diz o que acontece quando está ligado, nunca "Ativar X".
